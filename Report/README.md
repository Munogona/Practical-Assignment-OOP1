# Bank Account OOP Assignment Report

## 1. Introduction
This project demonstrates the application of Object-Oriented
Programming (OOP) principles in Java through a simple banking system.

## 2. Objectives
- To implement classes and objects in Java.
- To demonstrate inheritance and polymorphism.
- To apply encapsulation and abstraction.
- To simulate banking transactions.
- To test the functionality of different account types.

## 3. Program Description
The banking system consists of four Java classes:

### Account.java
Provides the common properties and methods used by bank accounts.

### SavingsAccount.java
Represents a savings account with interest calculations
and minimum balance requirements.

### CurrentAccount.java
Represents a current account that supports overdrafts
and account maintenance fees.

### BankDemo.java
Contains the main method used to demonstrate and test
the banking system.

## 4. OOP Concepts Applied

### Encapsulation
Account data is managed through methods that control
how account information is accessed and modified.

### Inheritance
SavingsAccount and CurrentAccount inherit common
properties and methods from Account.

### Polymorphism
Different account types perform withdrawals and
month-end processing differently.

### Abstraction
The Account class provides a common structure for
different types of bank accounts.

## 5. Testing and Results
The program was executed using Visual Studio Code.

The tests demonstrated:
- Successful deposits.
- Rejection of negative deposits.
- Minimum balance validation.
- Current account overdrafts.
- Savings account interest calculations.
- Current account maintenance fee deductions.

All demonstrated operations produced the expected results.

## 6. Conclusion
This assignment helped me understand how Object-Oriented
Programming concepts can be applied to a practical system.

Through the implementation of different bank account types,
I gained experience working with inheritance,
encapsulation, polymorphism, and abstraction in Java.
